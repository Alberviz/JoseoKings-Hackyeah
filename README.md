# CrohnCare

A Progressive Web App for people living with Crohn's disease: find the nearest accessible restroom fast, and check restaurant menus for your trigger foods. Built at HackYeah 2026, Kraków.

## Quick start

```sh
pnpm install
cp .env.example .env.local
pnpm dev
```

Open http://localhost:3000.
