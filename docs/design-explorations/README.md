# Design explorations (Álvaro lane)

**Branch:** `design/alvaro-explorations`  
**Rule:** outside product code — do **not** merge into app behaviour until Alberto picks a direction.  
**Audience:** children 8–12. Friendly young Kraków-inspired dragon. Never sad or sick. Fire bar only rises. Reward the act, never the answer.

Claude's published mockup (Meadow / Notebook / Dusk) is a reference only — these packs go elsewhere on purpose.

## How to view

Open any `.html` file in a browser (double-click or drag into Chrome). Phone frame is ~390×844.

```
docs/design-explorations/
  README.md                 ← this index
  dragons/                  ← SVG companions + egg stages
  ui/                       ← full flow mockups (HTML)
  STYLE_NOTES.md            ← short rationale per direction
```

## Product rails (must keep)

- Check-in core stays `belly-comfort` / `energy` / `play-pace` (0–2). Extra chips (Calm/Strong/Amazing) are optional chrome only.
- Alone / Family / Someone else: child chooses.
- No clinical meters, no punishment, 48px targets, English UI.
