# Style notes (batch 1)

## D1 Felt Friend

Plush toy on a pale wool desk. No hard shadows. Fire bar = embroidered felt strip. Coins = wooden tokens. Good for “safe and huggable”.

## D2 Linocut Night

Cream paper, indigo ink, rough registration. Feels hand-made (not generic UI kit). Strong identity for Kraków legend storytelling.

## D3 Sticker Arcade

Die-cut white borders, slight paper lift. Shop items read as stickers you peel onto the dragon. Energetic but still gentle (no aggressive reds).

## D4 Graph Crayon

Blue grid + wax strokes. Looks like a school diary the child owns. Calm/Strong chips drawn as crayon ovals.

## D5 Legend Glass

Lead lines + jewel colours. Fire bar = warm amber pane. More ceremonial; pair with quiet motion, not loud game juice.

## D6 Clay Geometry

Matte clay blobs, soft studio light. Accessories look pinched from clay. Softens “game economy” so it does not feel pay-to-win.

## D7 Tiny Pixel

Chunky pixels, limited palette, no Mario references. Good for “game HUD” without symptom meters. Keep faces soft (round eyes, small smile).

## Shared UX skeleton (all U-packs)

1. Home: dragon centre, fire top-left, coins top-right, PLAY, Shop / Food / Customize
2. Company: Alone / Family / Someone else
3. Feeling before: Calm / Strong / Amazing (extra chips)
4. Mission: Dragon Breathing + ring + “We did it!”
5. Feeling after: Exhausted / Chill / Great
6. Chest: +12 always
7. Shop + Customize as specified in Alberto’s brief
